ARQUITETURA MODULAR COMPOSÁVEL

Quatro capacidades independentes. Zero dependência forçada.

Diferente de ferramentas legadas de pipeline linear, os módulos da Tessera são independentes por design. Use Discovery, Masking, Subsetter ou CDC isoladamente ou combinados de acordo com seu fluxo de trabalho.

PRONTO lib · Go framework

Discovery

Identifica e classifica colunas e estruturas JSON em domínios de dados sensíveis (PII, pagamentos, CPF) a partir de metadados e amostras. Gera um inventário estável sem realizar I/O direto.

  • Filosofia Recall-First (não deixa PII passar)
  • Classificadores PATH e DATA independentes
  • Resolução de esquemas ofuscados ou SAP
Especificações →
PRONTO lib · Go framework

Masking

Mascaramento determinístico e key-driven com preservação estrita de formato (FF1 NIST SP 800-38G). O mesmo dado mascarado gera saídas byte-idênticas entre sistemas, preservando Foreign Keys.

  • 13 algoritmos de criptografia e ofuscação
  • Validação de formato (Luhn, CPF, IBAN)
  • Integração com AWS KMS e K8s Secrets
Especificações →
CORE PRONTO app · Web, CLI & K8s

Subsetter

Extrai fatias pequenas e referencialmente íntegras de grandes bancos relacionais para DEV e testes. Resolve dependências circulares com Tarjan SCC e executa em ondas ordenadas.

  • Grafo em Neo4j para FKs físicas e lógicas
  • PostgreSQL, MySQL, SQL Server, Oracle, Mongo
  • Três superfícies: Web UI, CLI YAML e Operador K8s
Especificações →
EM HARDENING app · Go engine

CDC & Snapshot

Coordena um snapshot inicial MVCC-consistente com stream incremental ordenado por commit (LSN/GTID), gravando JSONL canônico no Amazon S3 ou disco. Sem Debezium ou Kafka.

  • PostgreSQL 16+ (pgoutput) e MySQL 8+ (binlog)
  • Entrega Effectively-Once com marcadores S3
  • Captura de DDL (ALTER, CREATE, DROP)
Especificações →
ROADMAP Data Environment Lifecycle (Operador Kubernetes)

Orquestração completa de réplicas efêmeras de banco de dados em contêineres: provisionamento, refresh, snapshot instantâneo e rollback sob demanda para desenvolvedores e agentes autônomos.
