2. Tessera Masking

Solicitar Documentação →

Framework Go · Criptografia Determinística Key-Driven · FF1 NIST SP 800-38G

O determinismo matemático é o pilar da integridade relacional da Tessera: mesma chave + mesma config + mesmo input = saída byte-idêntica. Ao aplicar o mascaramento em repouso (Static Masking), chaves estrangeiras e identificadores entre diferentes microsserviços continuam se relacionando perfeitamente sem nunca revelar dados brutos.

✕ O Problema: Mascaramento Comum Quebra Testes

Ao mascarar bancos para ambientes de testes e QA, ferramentas tradicionais geram valores aleatórios desconectados. O mesmo cliente 1042 vira FAKE-119 no PostgreSQL e vira RANDOM-842 no Oracle.

Impacto: A chave estrangeira (FK) se quebra. As consultas com JOIN retornam zero registros e toda a suíte de testes de software falha!

✓ A Solução Tessera: Criptografia Determinística (NIST FF1)

A Tessera garante consistência matemática via KMS: mesma chave + mesmo dado = mesma saída mascarada, mesmo operando em bancos de dados totalmente separados.

Benefício: O cliente 1042 vira exatamente "US-981-D" em todos os microsserviços simultaneamente. As consultas e testes funcionam 100%, com dados sensíveis (PII) totalmente anônimos e protegidos (LGPD).
